# 赛事级审核方法 v1

本文件用于维护和复核，不作为首页营销文案。

## 审核范围

每场已审核赛事必须补齐：

- 精确主办或承载关系
- 地区、语言、参赛资格与费用
- 截止时间及时区
- 官方入口与证据链接
- 权威性、履历价值、成长价值（1–5）
- S/A/B/C/U/R 等级与证据置信度
- 资格、费用、平台、开源、现场参与和数据合规风险

## 评级边界

- 评级判断赛事本身的质量，不代表所有用户都适合参加。
- 资格受限、资格赛已截止或必须现场参与的赛事可保留质量评级，但必须降低推荐排序并显著提示。
- 未完成赛事级审核的记录只能使用 `U · 待核验`。
- 商业合作、推广和赞助不得影响评级与推荐分数。
- 严重风险优先于总分。

## 证据要求

优先使用赛事官网、主办方公告、官方规则、官方承载平台规则页。聚合页只能用于发现线索，不能单独支撑高置信度评级。
